## 🌟 ¡Bienvenidos al Seminario!

Este espacio académico está diseñado para integrar tecnologías de vanguardia en el desarrollo de software moderno.

Durante este ciclo, combinaremos la potencia de **Python (FastAPI)** en el backend, la versatilidad de **Node.js** para arquitecturas concurrentes y la robustez de **Angular** para la construcción de interfaces de usuario escalables.

---

## 🧭 Contenido y Hoja de Ruta de la Materia

Nuestros contenidos se estructuran en los siguientes bloques clave:

### 1️⃣ Fundamentos de Arquitectura Web y Modelado

* Principios de diseño orientados a servicios y separación de responsabilidades.
* Diseño de contratos de API RESTful estables y seguros.
* Gestión de control de versiones y entornos de desarrollo limpios.

### 2️⃣ Backend de Alto Rendimiento con FastAPI (Python)

* Introducción a la asincronía (`async/await`) en Python mediante Starlette.
* Validación estricta de datos en tiempo de ejecución con **Pydantic**.
* Generación automática de documentación interactiva (Swagger UI / OpenAPI).
* Conexión a bases de datos y gestión de dependencias en FastAPI.

### 3️⃣ Ecosistema de Microservicios y Gateway con Node.js

* El modelo de bucle de eventos (*Event Loop*) y procesamiento no bloqueante.
* Creación de pasarelas de API (*API Gateways*) y microservicios complementarios.
* Gestión de paquetes, scripts y manejo de peticiones HTTP en entornos JavaScript.

### 4️⃣ Interfaces de Usuario Escalables con Angular

* Arquitectura basada en componentes y tipado estricto con **TypeScript**.
* Gestión avanzada de formularios, enrutamiento y servicios HTTP.
* Consumo de APIs, interceptores de seguridad y manejo de flujos reactivos con RxJS y Signals.

### 5️⃣ Integración Full Stack y Despliegue

* Comunicación de extremo a extremo entre el cliente (Angular) y los servidores (FastAPI / Node.js).
* Manejo seguro de variables de entorno y configuración de entornos de producción.
